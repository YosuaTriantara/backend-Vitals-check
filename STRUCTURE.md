## 📋 Detail Setiap Folder

### `src/`
Folder utama berisi semua source code aplikasi backend.

---

### `src/config/`
**Tanggung jawab**: Konfigurasi dan inisialisasi external dependencies.

| File | Purpose |
|------|---------|
| `db.js` | Export Prisma client instance yang siap pakai di services |
| `env.js` | Load & validasi env vars di startup (prevent runtime crashes) |

**Contoh usage di file lain**:
```js
import prisma from '../config/db.js';
const users = await prisma.user.findMany();
```

---

### `src/routes/`
**Tanggung jawab**: Mendefinisikan routes dan menghubungkan ke controllers.

| File | Endpoints |
|------|-----------|
| `auth.routes.js` | `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me` |
| `users.routes.js` | `GET /api/users/profile`, `PUT /api/users/profile` |
| `screening.routes.js` | `POST /api/screenings`, `GET /api/screenings`, `GET /api/screenings/:id`, `DELETE /api/screenings/:id` |
| `education.routes.js` | `GET /api/education?category=low\|medium\|high` |

**Pattern**:
```js
// auth.routes.js
import { register, login, getMe } from '../controllers/auth.controller.js';
import { protect } from '../middlewares/auth.middleware.js';

router.post('/register', register);
router.post('/login', login);
router.get('/me', protect, getMe);
```

---

### `src/controllers/`
**Tanggung jawab**: Request handler — parse input, call service, send response.

| File | Methods |
|------|---------|
| `auth.controller.js` | `register()`, `login()`, `getMe()` |
| `screening.controller.js` | `createScreening()`, `getScreenings()`, `getScreening()`, `deleteScreening()` |
| `user.controller.js` | `getProfile()`, `updateProfile()` |

**Pattern**:
```js
// screening.controller.js
export async function createScreening(req, res, next) {
  try {
    const result = await screeningService.createScreening(req.user.id, req.body);
    res.json({ success: true, data: result });
  } catch (error) {
    next(error);  // Pass ke error.middleware
  }
}
```

---

### `src/services/`
**Tanggung jawab**: Business logic — kalkulasi, integrasi API eksternal, DB operations.

| File | Responsibilities |
|------|------------------|
| `screening.service.js` | Hitung BMI, panggil inference, simpan ke DB, ambil education content |
| `inference.service.js` | Panggil Model API dengan retry logic untuk 503 error |

**Alur**: Controller → Service → (Database/External API) → Response

**Contoh**:
```js
// screening.service.js
export async function createScreening(userId, inputData) {
  const bmi = calculateBMI(inputData.weight_kg, inputData.height_cm);
  
  const prediction = await inferenceService.predictRisk({
    ...inputData,
    bmi
  });
  
  const screening = await prisma.screening.create({
    data: { userId, ...inputData, bmi, ...prediction }
  });
  
  return screening;
}
```

---

### `src/middlewares/`
**Tanggung jawab**: Request preprocessing dan error handling.

| File | Purpose |
|------|---------|
| `auth.middleware.js` | Verifikasi JWT dari Authorization header, attach `req.user` |
| `error.middleware.js` | Catch errors, log, standardize response format |
| `validate.middleware.js` | Validasi request body dengan Joi schema, return 400 jika invalid |

**Pattern**:
```js
// auth.middleware.js
export function protect(req, res, next) {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ error: 'Unauthorized' });
  
  try {
    req.user = jwt.verify(token, process.env.JWT_SECRET);
    next();
  } catch (error) {
    res.status(401).json({ error: 'Invalid token' });
  }
}

// Penggunaan di route
router.get('/screenings', protect, getScreenings);
```

---

### `src/validators/`
**Tanggung jawab**: Mendefinisikan schema validasi input.

| File | Schemas |
|------|---------|
| `screening.schema.js` | `createScreeningSchema`, `updateScreeningSchema` |

**Contoh**:
```js
// screening.schema.js
import Joi from 'joi';

export const createScreeningSchema = Joi.object({
  age: Joi.number().integer().min(1).max(150).required(),
  gender: Joi.string().valid('male', 'female').required(),
  height_cm: Joi.number().positive().required(),
  weight_kg: Joi.number().positive().required(),
  systolic_bp: Joi.number().integer().positive().required(),
  diastolic_bp: Joi.number().integer().positive().required(),
  blood_glucose: Joi.number().positive().required()
});
```

---

### `src/utils/`
**Tanggung jawab**: Helper functions & utility classes.

| File | Purpose |
|------|---------|
| `apiError.js` | Custom error class dengan statusCode & message |
| `riskMapper.js` | Mapping `risk_score` → `risk_category` (fallback jika Model API tidak provide) |

**Contoh**:
```js
// apiError.js
export class ApiError extends Error {
  constructor(statusCode, message, details = null) {
    super(message);
    this.statusCode = statusCode;
    this.details = details;
  }
}

// Usage
throw new ApiError(400, 'Validasi gagal', { field: 'age', reason: 'harus > 0' });

// riskMapper.js
export function mapRiskCategory(risk_score) {
  if (risk_score < 0.3) return 'low';
  if (risk_score < 0.6) return 'medium';
  return 'high';
}
```

---

### `prisma/`
**Tanggung jawab**: Database schema & migration management.

| File | Purpose |
|------|---------|
| `schema.prisma` | Database model definitions (User, Screening, EducationContent, dll) |
| `migrations/` | Generated migration files (do not edit manually) |

**Workflow**:
1. Edit `schema.prisma`
2. Run `npx prisma migrate dev --name <migration_name>`
3. Generated migration file di `migrations/`
4. Database diupdate otomatis

## 🔌 Request Flow Example

```
User POST /api/screenings dengan data kesehatan
         ↓
Express route handler di screening.routes.js
         ↓
protect middleware → verifikasi JWT, attach req.user
         ↓
validate.middleware → validasi dengan screening.schema.js
         ↓
screening.controller.createScreening() → parse data
         ↓
screening.service.createScreening() → business logic:
  1. Hitung BMI
  2. Panggil inference.service.predictRisk()
  3. Simpan hasil ke DB via Prisma
  4. Ambil education content
         ↓
Hasil response kembali ke controller
         ↓
error.middleware (jika ada error) → standardize error response
         ↓
Response dikirim ke client
```

## 🛠️ Setup Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Environment
```bash
cp .env.example .env
# Edit .env dengan nilai actual (DATABASE_URL, JWT_SECRET, dll)
```

### 3. Setup Database
```bash
# Generate Prisma client
npx prisma generate

# Run migrations
npx prisma migrate dev

# (Optional) Seed data
npx prisma db seed
```

### 4. Start Development Server
```bash
npm run dev
```

## 📌 Naming Conventions

### Files
- Use kebab-case untuk file names: `auth.controller.js`, `screening.service.js`
- Folder names: kebab-case juga: `src/`, `prisma/`

### Functions
- Use camelCase: `createScreening()`, `predictRisk()`, `getMe()`

### Database
- Use snake_case untuk column names: `created_at`, `risk_score`
- Use PascalCase untuk model names: `User`, `Screening`, `HealthProfile`

### Routes
- Use kebab-case & lowercase: `/api/screenings`, `/api/users/profile`
- Tidak ada underscore atau uppercase di URL
